# 文档解析依赖审查

15b/16 DOCX worker 仅在字节数、条目数预检后调用格式库。不增加宿主依赖、进程执行、外部请求、
解压到磁盘、OCR 或 Office 集成。zip 精确固定为 9.0.1、关闭默认功能，只开启
`deflate-flate2-zlib-rs`；quick-xml 精确固定为 0.42.0、关闭默认功能。分别负责 CRC 校验的
ZIP 解压及 XML 命名空间事件解析，避免重新实现通用格式。核验日期：2026-10-19（UTC+08）。

精确版本的日期及未撤回状态均通过发布者的
[crates.io 版本 API](https://crates.io/api/v1/crates/zip/9.0.1) 核验；将 URL 末尾的包名和版本替换
即可复查其他行。所有新增版本均已发布至少七天。Cargo 最初解析到 equivalent 1.0.3（10 月 13 日），
因不足七天而将锁文件固定为 1.0.2；不要随意更新。原始许可文本保存在
`licenses/documents/THIRD-PARTY-NOTICES.txt`，双许可包选择 MIT；既有依赖不变。

审查包含 quick-xml 0.41 起修复的命名空间分配与属性解析问题，以及 ZIP 9.0.0 起的解压 API 修复。
原始公告：[XML 分配](https://rustsec.org/advisories/RUSTSEC-2026-0195.html)、
[XML 属性](https://rustsec.org/advisories/RUSTSEC-2026-0194.html)、
[ZIP](https://rustsec.org/advisories/RUSTSEC-2026-0367.html)。这是针对性源码和版本审查，
并不声明完整依赖审计无漏洞。worker 从不调用解压到文件系统的 API。

在调用 ZIP 构造器之前，worker 拒绝 ZIP64、多磁盘和加密包，验证中央目录的精确边界、
数量、唯一名称、本地头一致性与非重叠载荷；仅以限定大小缓冲读取固定 OPC 元数据和
word/document.xml。解压以实际输出字节数限额加一为界，不信任声明长度；完整读取校验 CRC。
XML 禁用 DTD 与自定义实体、严格 UTF-8 或 BOM 标记 UTF-16 解码、限制深度、属性数和命名空间绑定数。
不支持的内容返回明确错误或部分观察结果。

PDF 解析另有后续审查。本切片不增加 PDF 依赖、不声明 PDF 支持；CSV/DOCX 不能替代 PDF 基准。

## PDF 基础依赖核验（15c/16，2026-10-19）

自主实现的有界容器语法仅直接引用已精确锁定的 flate2 1.1.10，关闭默认功能并
选择 zlib-rs。两者版本、许可及日期已在上文核验，不新增任何解析依赖包或版本。
底层解码同时核验实际输出大小、zlib 校验和/结束标记及尾随输入。

本切片评估后未采用通用解析库。lopdf 0.42 尚无 0.44 才加入的可配置流限制；
较新版本即使关闭默认功能仍引入必选加密依赖树。核验发现相关缓冲区转换需
[上游 inout 修复](https://github.com/RustCrypto/utils/pull/1556)，其后续 0.2.4
在核验时发布不足七日；没有为满足日期规则选用受影响旧版，也没有维护私有补丁。
候选 lopdf/加密依赖均未保留于锁文件。可复核
[lopdf 更新日志](https://github.com/J-F-Liu/lopdf/blob/main/CHANGELOG.md)及
[inout 0.2.4 发布信息](https://crates.io/api/v1/crates/inout/0.2.4)。
这属于针对性源码核验，并非全面 PDF 合规或安全审计结论。
