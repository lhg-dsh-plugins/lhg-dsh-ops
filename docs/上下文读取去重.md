# 感知当前上下文的 Native 读取去重

English: [Context-aware Native read deduplication](context-read-dedup.md).

只有能够证明此前一次成功读取的完整正文确实进入最近一次成功完成的普通模型请求，OPS 才会把重复 Native 文本读取的行号正文替换为“未改变”的引用。结果仍保留路径、行范围、版本、完整性和续页提示，并注明此前工具调用和持久消息的标识。计数说明这些行已重新验证，不会声称本次再次显示了正文。

每次调用仍执行正常权限检查与 worker 读取。节省的是重复模型输出和上下文字节，不是 IO 缓存，也不宣称 IO 加速。PTC 的规范值及嵌套传输内容保持完整。首次读取、引用反而更长的短文本、十六进制输出、被裁切的输出，以及证据不明的情况，均返回正常全文。

## 证据与失效条件

以下事实必须全部一致：

- 本组件拥有的成功顶层读取，通过注册表生成的执行 token 与最终 tools/result 关联。
- 已提交的 tool/result 消息身份、来源调用身份和逐字正文。用户消息或参数里出现相同文字不足以构成证据。
- 最近一次成功完成的普通 llm/stream 请求包含相同消息和正文，且此前存在匹配的 assistant 工具调用与参数。
- 同一个活动会话对象、surface.contentGeneration、路径、文件身份、大小、纳秒修改/变更时间、版本、请求参数/范围，以及本次新读取渲染的正文。

普通请求开始前清除已有证明。失败、取消、未结束或被较新请求取代的请求不能恢复它。压缩和标题等辅助请求不能提供证明；较早请求晚完成也不能覆盖较新请求。上下文替换和消息投影都会使记录失效。文件未变或正文仅存在历史日志中，都不够。

权限模式变化、代理/会话销毁、组件卸载，以及修改类或未知工具的结果会丢弃证据。缺少信号时静默关闭优化。证据归挂载组件及调用代理所有。最多保留 16 个代理，每个代理 32 条记录和 2 MiB 正文；淘汰后返回全文。不新增磁盘缓存、宿主注册表替换或依赖。

支持 ops_inspect_local_file 和 ops_read_files。重复批次必须匹配此前整个批次的消息与参数，并分别重新验证每个返回文件；只要其中一个文件变化、缺失、被裁切或缺少证据，就保留全部正文。存在待处理文件、失败项或存储引用时不启用去重。限定行范围的读取仍可能没有覆盖整个文件，原有完整性和续页提示会保留。

## 固定宿主版本的研究依据

研究直接检查了本地安装、锁文件固定的 0.2.0-rc.2 npm 包中的一手来源：

| 来源 | 契约 |
| --- | --- |
| @deepseek-ai/dsh-llm/lib/types/types.d.ts：GenerateOptions | messages 是模型可见的有序请求；辅助调用带有 purpose。 |
| @deepseek-ai/dsh-llm/lib/types/index.d.ts：llm/stream；lib/index.js：适配器派发 | 公开流事件包围适配器派发；文本工具正文保留内容和消息身份。 |
| @deepseek-ai/dsh-llm/lib/types/message.d.ts | 工具消息具有稳定 ID、角色、来源和调用 ID；assistant 工具调用保留原始参数。 |
| @deepseek-ai/dsh-session/lib/types/surface.d.ts；lib/index.js：applySurfacePlan | 上下文替换和消息投影改变 contentGeneration，普通尾部追加不会。 |
| @deepseek-ai/dsh-tools/lib/types/index.d.ts：ToolDefinition、ToolExecution、tools/result | 最终处理只能修改内容；其他字段与 token 归注册表所有；最终结果被冻结；嵌套调用带有 parent。 |

测试使用真实 Cordis 工具、带记录适配器的 LLM runtime、SessionStore、Native worker 及宿主 sandbox/subprocess 服务。测试实际执行压缩使用的上下文替换机制与消息投影注册，不宣称验证外部压缩器的摘要质量。覆盖输出减少与规范值完整性、实时权限、变化/伪造身份、辅助/最新/并行请求、元数据/范围变化、嵌套传输、策略内容、压缩/投影、卸载和保留上限。

依次运行 npm run build:ptc、npm run build 和 node test/run.mjs context-read。缺少 worker 只能算跳过，不能算通过。
